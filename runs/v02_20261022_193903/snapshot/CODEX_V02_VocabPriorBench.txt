五、四条件的唯一构造

令 C 为 artifacts/codes.pt 原始 output 表，不是 Lp 训练后的表。
令 r_v = ||C_v||_2，在 CPU FP64 中计算行范数。
令 S 沿用 V0.1 的精确 FP32 表达式：
    torch.where(C >= 0, 1., -1.) / math.sqrt(128)
即 sign(0)=+1，C 和 S 两个锚点必须与 V0.1 Fp/Sp 的 initial output_codes tensor hash 一致。

定义：
- 非零行：U_v = C_v / r_v；
- 零行 r_v=0：U_v = S_v，这是预先固定的退化行方向约定；
- RS_v = r_v * S_v。

U 与 RS 在 CPU FP64 构造，然后转 FP32 存储。C/S 保持上述原 FP32 值。
不要 clamp r_v 到 epsilon 后再声称所有 U 行单位范数。正的极小行仍用 FP64 相除并检查有限性。零行不删除、不改 token ID。

四个条件：
C  ：连续方向，原始行范数，即原表 C；
U  ：连续方向，单位行范数，即 U；
RS ：sign 方向，原始行范数，即 r*S；
S  ：sign 方向，单位行范数，即 S。

所有条件输入表均为原连续 C_in 且冻结；输出表也全部冻结。主干及两个投影可训练，仍为 444,928 个公共可训参数。

四条件共享原 prepared.pt 中的 pi，输出偏置全部为同一 FP32 log(pi)，并冻结。
正确 logits 为：
    logits_v(x) = T_v^T q(x) + log(pi_v)
例如 RS 为 r_v*S_v^T*q(x) + log(pi_v)，不能把 log(pi_v) 也乘 r_v。

不要再做每条件全局 RMS 校准、中心化、白化、旋转、温度调整或频率加权 RMS 对齐。报告原样描述量；如频率加权能量不同，这是干预的结果，不通过额外调参消除。

本轮 r 是指定的 L2 行范数控制，不是二值重建的最小二乘最优尺度。控制失败不能排除所有尺度方案；不得看到结果后临时添加最小二乘尺度第五臂。

十、唯一主要分析与事前判定

对每个 seed 的 step767 dev NLL，令 L(T) 表示条件 T 的 loss。
保留有符号差值：
    G      = L(S)  − L(C)
    D_r    = L(RS) − L(C)
    D_1    = L(S)  − L(U)
    N_cont = L(U)  − L(C)
    N_sign = L(S)  − L(RS)
    I      = D_1 − D_r = N_sign − N_cont

验证代数关系：
    G = N_sign + D_r = D_1 + N_cont
这是差值恒等式，不是因果中介分解。不得把某个消除比例直接命名为“解释了百分之多少语义”。

tau=0.05 nats/token，沿用探索性容忍值；两 seed 分别报告，不用平均值掩盖方向冲突，不把 token/块当独立训练重复，不做显著性或统计等价结论。

仅在八条轨迹有效且完整、桥接未留无法说明的漂移时，按以下优先级判定：

A. NORM_DOMINANT_IN_THIS_SCREEN
要求两个 seed 都满足：
    G > tau；
    abs(D_r) <= tau；
    abs(D_1) <= tau；
    N_cont > tau；
    N_sign > tau。
含义仅为：在本设置与终点，匹配两种行范数后方向差均处于容忍区间，而去掉原行范数在两种方向下均增加 loss。
结论：当前约0.17差距主要伴随这个已知尺度因素。停止以该差距为独立论文核心推进，不包装“恢复行范数”为新方法。

B. DIRECTION_RESIDUAL_AT_BOTH_NORMS
要求两个 seed 都满足 D_r>tau 且 D_1>tau。
含义仅为：匹配原行范数和单位行范数时，sign 方向仍有同向代价，原差距不能只归因于丢失原行范数。
不得升级为语义损失、唯一机制、所有尺度解释被排除或论文成立。有限步优化和固定输出族仍是竞争解释。仅保留现象，结束运行。

C. INTERACTION_OR_COMPENSATION
若两个 seed 的 abs(D_r)<=tau，但未满足 A，且两个 seed 的 D_1>tau，则明确标记恢复 r 仅在该格补偿了方向变化。
不得因 RS 接近 C 就称“范数解释完整”。报告 I 及两条 norm effect，结束运行。

D. INCONCLUSIVE_OR_OTHER_PATTERN
其他未满足 A/B/C 的模式，包括 seed 冲突、反向效果、只有一种行范数下有残差或新现象。逐值报告，不事后修改阈值/条件使其归类为成功，不追加实验。若 G 本身不再超过阈值也照实报告；是否属于 B/C 仍按各自公式判定，不另加未定义的门槛。

若出现 BLOCKED、INVALID、INCOMPLETE 或 BRIDGE_UNRESOLVED，优先报告该状态及已完成结果，不套用上述机制标签。

step0/100 只作预定训练轨迹描述；不得看曲线改主要终点。

十一、解释边界与研究决策

报告至少说明：
- r*S 的逐行缩放通常改变输出列空间，不能说四格只有优化不同、函数类完全相同。
- 存在可训练输出投影 P 时，C→C*A、P→A^(-1)*P 的可逆右变换可保持函数，却改变原始行余弦几何。因此原表 margin 只是参数化相关代理量，不自动具有因果或语义意义。
- 同初态、相同步数是配对控制，不能证明各模型都已优化收敛。
- 两 seed、一 donor、一语料、一宽度、短预算，只支持本设置的探索结论。
- 恢复原 L2 范数不是所有尺度方案的代表，不支持过宽的否定结论。
- 四表全为 FP32，没有真实 bit packing 或新 kernel。
- 已知的范数恢复、符号加幅度表示及几何增益预测不是本项目新贡献。

在 RESEARCH_DECISION.md 写不超过一页的当前投入判断：
“现有冻结/符号化差距是否足以成为 CAS 一区或 CCF A/B 独立论文主线？”默认不能因存在残差而回答是。
若出现仍值得记录的现象，可写一个精确、可证伪且区别于近邻的新问题草案，并列明竞争解释和未解决点；不实现它、不执行新训练、不打开 holdout，也不以组合已有模块充当创新。
若没有这样的具体问题，就明确建议暂存这条路线，保留工程资产和负结果，停止继续加基础诊断。

无论 A/B/C/D 哪个结果，NEXT 都应是 PAUSE_CURRENT_CLAIM_FOR_RESEARCH_DECISION，而不是 START_V1。不要附带自动执行的 V0.3/V1 计划。
