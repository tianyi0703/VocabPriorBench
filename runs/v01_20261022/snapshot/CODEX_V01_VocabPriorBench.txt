四、定向文献与数学核对

数学说明必须准确：
- 以列向量记号，固定输出表 C_out 时 logits(x)=C_out q(x)，故 logits 受固定列空间约束。
- final_LN 有可训练 bias，因此不能说没有独立输出 bias 就完全无法学习词频；它只能经同一固定输出子空间产生偏置。
- 对严格为正的分布 pi，常量输出可精确表示它要求 log(pi) 属于 col(C_out)+span(1)。
- 所有现有臂的 hidden/code width 都是 128。即使未来使用 512 维表，只要学生 hidden 仍是 128 且输出为线性映射，不能称为解除 128 维 softmax rank 限制。
- sign 码的唯一性、每个 token 能否成为 argmax、任意条件概率分布的可表示性，是不同问题。不得从低维或邻距直接推出“某 token 永远无法预测”。
- 增加固定 bias 同时改变频率信息与 logits 所在的仿射空间；结果只能证明对该干预敏感，不能把唯一因果机制直接命名为“词频解释完毕”。

六、CPU 无上下文输出诊断

只对初始连续输出表和初始 sign 输出表，各拟合一个 128 维常量向量 a：
  q_a = softmax(C_out @ a)
  L(a) = logsumexp(C_out @ a) - pi^T(C_out @ a)

使用 float64、稳定 logsumexp 和可复查梯度；从零向量起，固定优化器、容差与迭代上限，不按 dev 选择它们。可用现有依赖中的 L-BFGS。记录实际停止条件、迭代数、目标值、梯度范数与耗时。

分别报告：
- 平滑 pi 的熵 H(pi)；
- 已实现的 L(a)-H(pi)，仅在收敛证据充分时称“近似拟合最优差距”，否则称当前优化残差；
- train 拟合得到的 q_a 在完整 dev 上的 NLL；
- 直接使用训练 pi 的完整 dev NLL；
- C_out 的数值秩/列空间诊断如确有需要，使用小矩阵或 V×128 分解，不构造 V×V 矩阵。
- 验证加入 b=log(pi) 且 a=0 时，理论上 softmax(b)=pi；实际数值在预设容差内一致。

这只测“单一、无上下文分布”的表达与拟合，绝不能把它称为有上下文语言模型 NLL 下界。不得仅凭该诊断就宣称解释了 V0 的训练差距。

七、执行六条件输出端对照

输入一律为同一份连续 PCA128 冻结 C_in。主干、输入投影、输出投影均可训练，维度与 V0 相同。只改变输出码表及固定输出 bias：

L0：连续输出表可训练，bias 为全零固定向量。
F0：连续输出表冻结，bias 为全零固定向量。
S0：sign 输出表冻结，bias 为全零固定向量。
Lp：连续输出表可训练，bias 固定为 log(pi)。
Fp：连续输出表冻结，bias 固定为同一 log(pi)。
Sp：sign 输出表冻结，bias 固定为同一 log(pi)。

- L/F 的初始连续输出表逐值相同；S 使用同一 donor/同一 PCA 变换后的预定 sign/RMS 规则。
- 六条件的输入码表都逐值相同并冻结。S0/Sp 只符号化输出，不能冒充原 V0 的 C。
- 全零与 log(pi) bias 均作为相同计算路径中的固定 buffer；不训练 bias，不加各条件专用参数。
- 每个 seed 下主干/投影初态从公共保存文件加载；不要顺序续训，不要加载上一条件最终状态，不共享可被更新的表存储。
- 保持 lr=3e-4、AdamW、weight_decay=.01、clip=1、seq128、microbatch2、accumulation2、bf16 autocast/FP32参数、dropout0，与 V0 的既定实现一致。
- 先做必要的短数值检查：同 bias 下 L/F 初态前向一致；输入始终不变；只有 L 条件输出表更新；固定 bias 与冻结表不变；有效计数正确；损失/梯度有限。
- 沿用已通过且未修改的基础数值检查，不堆叠镜像测试。
- 两 seed × 六条件共 12 条短轨迹，按事前固定顺序串行，第二 seed 可采用反向条件顺序减少同序影响。
- 不跑原维 D/E、随机 R、置换 P，不扩模型，不改 tokenizer，不训练到收敛，不把缺少这些基线包装为正式论文实验完备。

预算监督器在启动任何 GPU 进程前检查剩余累计预算。预计无法完成全部轨迹时，保留已完成记录并返回 BUDGET_INCOMPLETE，不根据已观察结果缩短某一臂或挑选有利子集。数值错误的修复及重跑也计入上限；任何实现改动必须对受影响比较保持一致，并保留被取代运行。

本轮不要求持续热稳态测速；短跑速度仅用于记录实际开销，不外推 12 小时或更大模型。仍报告实际 allocated/reserved、全设备占用的不同口径；float32 sign 表仍不是 1-bit GPU 存储。

八、主要指标和一次性筛选规则

每个 seed、每个预定评价点分别报告：
  delta_freeze_0 = NLL(F0)-NLL(L0)
  delta_freeze_p = NLL(Fp)-NLL(Lp)
  delta_sign_0   = NLL(S0)-NLL(F0)
  delta_sign_p   = NLL(Sp)-NLL(Fp)

分别列出：
  interaction_freeze = delta_freeze_p-delta_freeze_0
  interaction_sign   = delta_sign_p-delta_sign_0

保留正负号，不能只报所有模型加 bias 后都变好的总量。不要直接将这些新条件与 V0 的 A/B/C 组成统计对照。
另报辅助量 context_gain=NLL(训练 pi 在 dev)-NLL(模型在 dev)。它表示超过固定 unigram 的预测收益，不直接等于语义能力。若模型尚未在两个 seed 上稳定优于 unigram，即使存在残差，也要明确本轮尚不足以讨论成熟的上下文建模机制，不自动据此扩大训练。

保存 token 加权 NLL 总和与分母；如现有打包元数据支持，可保存逐文档统计。没有可靠映射则明确不支持文档级重采样，不伪造映射。两个 seed 的原始结果都要展示，不把 token、块或文档当成独立训练 seed。

为让本轮筛选有终点，使用 tau=0.05 nats/token 作为预算决策阈值；它只是本项目探索性容忍值，同 tokenizer 下约相当于 5.1% PPL 比值，不来自文献，不是显著性、等价或发表标准，不得事后调整。

对冻结与 sign 两个效应分别在最终评价点分类：
1. PRIOR_SENSITIVE_IN_THIS_SCREEN：
   两 seed 的无先验差距方向相同且各自绝对值都大于 tau；加入先验后两 seed 各自的绝对差距都不超过 tau，且各自不超过原无先验差距的 25%。
   解释：当前差距对共同先验干预敏感，不值得仅凭这个差距启动 12 小时扩展。不能说全部因果机制已被证明。
2. RESIDUAL_TO_EXPLAIN：
   加先验后两 seed 的差距方向相同，绝对值各自仍大于 tau。
   解释：存在本轮值得解释的残差；没有证明新颖、语义损失、最终优劣或普适性。
3. NO_MATERIAL_GAP_IN_THIS_SCREEN：
   两 seed 在有/无先验下的绝对差距均不超过 tau。
   解释：这个小场景未提供超过筛选阈值的信号，不是正式等价结论。
4. 其余为 INCONCLUSIVE；不要自动追加 seed、改阈值、改终点或改数据救结果。

若冻结/sign 结论不同，分别保留，不合并为一个笼统成功/失败。
